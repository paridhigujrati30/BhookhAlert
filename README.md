# 🍽️ BhookhAlert — Restaurant Selection & Queue Management

## About the Project

BhookhAlert is a group project focused on helping users explore restaurants and interact with a restaurant queue system. The project includes restaurant selection and queue-related pages.

The project is currently **in progress**. The restaurant selection and queue pages have been developed to a usable stage, while the overall application remains incomplete.

## Features Developed

- **Restaurant Selection:** Browse and select restaurants.
- **Cuisine Selection:** Explore restaurant options based on cuisine.
- **Queue Interface:** Access the available queue-related page.
- **Website Styling:** CSS-based styling for the website interface.

*Feature descriptions reflect the current project state; not all planned functionality is complete.*
